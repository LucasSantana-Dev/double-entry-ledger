# 0025. Results write-up: final README and an article draft

- Status: accepted
- Date: 2026-11-16

## Context

The project exists to show, with evidence, how a ledger stays consistent under concurrency and failure. The evidence is spread over four phases, their specs, ADRs and benchmark data.

## Options

1. A final README with the results of phases 1 to 4 and a trace and dashboard screenshot, plus an article draft in the repo.
2. The README only.
3. Option 1 with the article in Portuguese and English.

## Decision

Option 1, decided by the repo owner. The draft goes under `docs/writeup/`. Publishing it outside GitHub is the owner's decision and action.

## Consequences

- The README stays the entry point: what is proven, by which test, with which numbers.
- The draft is written once, in English like the rest of the repo.
